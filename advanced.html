⚠️ Ventana emergente bloqueada por el navegador

El navegador impidió abrir la ventana segura del cuestionario. Para resolver este examen, debe permitir las ventanas emergentes en este sitio:

  1. Mire el extremo derecho de la barra de direcciones de su navegador (URL).
  2. Haga clic en el icono de Ventana emergente bloqueada (suele ser una ventana con una cruz roja o un icono de aviso).
  3. Seleccione la opción "Permitir siempre ventanas emergentes y redirecciones de este sitio".
  4. Haga clic en "Listo" y vuelva a pulsar el botón "Intentar resolver el cuestionario".

¿Qué pone a prueba este simulador?

En la plataforma educativa Moodle, la opción de seguridad JavaScript para exámenes intenta restringir acciones como copiar texto, imprimir o abrir herramientas de desarrollador mediante scripts en el cliente.

Este entorno permite a docentes, administradores y estudiantes analizar:

  • Si las políticas del navegador moderno bloquean la apertura de pop-ups no solicitados.
  • Cómo se comportan los atajos del sistema operativo y si los bloqueos de JavaScript son realmente infalibles.
  • Cómo reacciona el navegador cuando se trabaja con múltiples pantallas: si mover el cursor o hacer scroll en un segundo monitor dispara eventos blur o mantiene el foco en la ventana del examen.
